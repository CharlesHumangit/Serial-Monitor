# Serial Monitor
A Windows-based Serial Monitoring Tool for debugging and communicating with microcontrollers, featuring real-time data reception, auto-scrolling, timestamping, and search functionality.

🔹 Features
✅ Serial Communication Support – Connect to any available COM port with configurable baud rate. ✅ Real-Time Data Display – Monitor incoming serial data in an intuitive UI. ✅ Auto-Scrolling & Timestamping – Toggle automatic scrolling and append timestamps for better tracking. ✅ Search & Highlighting – Quickly locate specific data in the output. ✅ Dynamic UI Updates – Connection status and controls adjust in real-time.

📌 Getting Started
Requirements
Windows 7/10/11

.NET Framework 4.7+

Compatible COM device (Arduino, ESP8266, etc.)

Installation
Clone this repository:

bash
git clone https://github.com/Charleshumangit/Serial-Monitor.git
Open the project in Visual Studio 2015+.

Build and run the application.

🚀 Usage
Select an available COM port from the dropdown.

Choose the baud rate (e.g., 115200).

Click "Connect" to begin receiving data.

Use the search bar to find specific entries.

Toggle auto-scroll and timestamping as needed.
